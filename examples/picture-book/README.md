# The Elves and the Markdown Maker

A picture book and a narrated reel made from one set of sources: eleven spreads, one hand-drawn SVG each, and a
machine page whose dials really work. Read this example when you want a book whose pages are pictures rather than
prose and diagrams.

```sh
node make.mjs                        # figures/*.svg  ->  book.md, storyboard.md
node ../../build.mjs book.md -o index.html
node check-panel.mjs                 # the numbers the machine page shows
node ../../video.mjs storyboard.md -o video      # duration depends on the speech provider
```

- `figures/`: one SVG per spread, hand-written shapes in the book palette. This is the only place a picture is
  edited; both the book and the reel take it from there.
- `book.src.md`, `video.src.md`: the sources, with `{{figures/ch01.svg}}` where a picture goes.
- `book.md`, `storyboard.md`: generated by `make.mjs`. Edit the `.src.md` files instead.
- `index.html`: the built book. The panel on "Three Dials" simulates imaginary 35-word pages: turn the dials,
  press Run. It does not render or play audio, and its estimated duration is not the narrated reel’s duration.
- `video/`: the render run (manifest, per-beat frames and audio, `video.mp4`). Not committed; regenerate with the
  command above.

Two things worth knowing before copying this:

- Figures are sized 1000×420. `video.mjs` caps a scene's visual at 1120×360, so a wider drawing letterboxes.
- Captions still number the figures ("Figure 7."), because the build does that for every book. A real children's
  press run would drop them.
